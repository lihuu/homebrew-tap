# lihuu's Official Homebrew Tap

Official Homebrew Tap for CLI developer tools maintained by [@lihuu](https://github.com/lihuu).

## Available Formulae

| Formula | Description | Documentation |
| :--- | :--- | :--- |
| **`gpgkit`** | One command for the whole life of a GPG key | [Documentation](https://lihuu.github.io/li-tools/gpgkit) |
| **`certkit`** | Zero-dependency CLI for enterprise PKI and certificate management | [Documentation](https://lihuu.github.io/li-tools/certkit) |

## Quick Start

### 1. Tap the repository
```bash
brew tap lihuu/tap
```

### 2. Install Tools

#### Install gpgkit
```bash
brew install gpgkit
# or without tapping first:
brew install lihuu/tap/gpgkit
```

#### Install certkit
```bash
brew install certkit
# or without tapping first:
brew install lihuu/tap/certkit
```

### 3. Update Tools
```bash
brew update
brew upgrade gpgkit certkit
```
